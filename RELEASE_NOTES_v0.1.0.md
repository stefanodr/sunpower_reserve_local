## v0.1.0 – First release

### English
- Read-only, fully local integration for the SunPower Reserve (AlphaESS) via Modbus TCP — no cloud.
- Sensors: grid, battery (SOC, power, energy), inverter, PV1/PV2, total PV.
- Experimental sensors (grid current, cell voltages, temperature, house load…) disabled by default.
- Works alongside `sunpower_maxeon`, which remains needed for battery control.

### Italiano
- Integrazione locale in sola lettura per SunPower Reserve (AlphaESS) via Modbus TCP — senza cloud.
- Sensori: rete, batteria (SOC, potenza, energia), inverter, PV1/PV2, FV totale.
- Sensori sperimentali (corrente di rete, tensioni celle, temperatura, consumo casa…) disabilitati di default.
- Funziona insieme a `sunpower_maxeon`, ancora necessario per il controllo della batteria.
